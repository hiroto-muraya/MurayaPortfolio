# MurayaPortfolio

個人開発プロジェクトや技術的な取り組みをまとめたポートフォリオ。

## 技術スタック

Next.js (App Router) / TypeScript / Tailwind CSS / Biome / pnpm

## 開発

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm lint     # Biome
pnpm build
```

## 内容の編集

表示内容(自己紹介・スキル・経歴・制作物・リンク)はすべて `lib/profile.ts` にまとまっています。
